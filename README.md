# PreampState

PreampState optimizes signal flow with adaptive, real-time gain-control and auto-scaling capabilities in a single, programmable processor module.

With PreampState, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/PreampState.git`
2. `cd PreampState`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure PreampState, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
